这一节我们考虑一个闭合系统，即没有端口的系统，然后计算其能带结构。

首先定义一个闭合系统：

```python
def make_system(a=1, t=1.0, W=10, L=30):
    lat = kwant.lattice.square(a, norbs=1)
    syst = kwant.Builder()
    syst[(lat(x, y) for x in range(L) for y in range(W))] = 4 * t
    syst[lat.neighbors()] = -t
    return syst
```

然后计算其能带：

```python
def plot_bandstructure(flead, momenta):
    bands = kwant.physics.Bands(flead)
    energies = [bands(k) for k in momenta]
    plt.figure()
    plt.plot(momenta, energies)
    plt.xlabel("momentum [1/a]")
    plt.ylabel("energy [t]")
    plt.show()
```

接下来我们考虑加磁场之后的环形系统能带。加磁场的方法是在 hopping 项上加上一个相位因子，即 Peierls 替换：

$$
t \rightarrow t \exp\left(i \frac{e}{\hbar} \int \vec{A} \cdot d\vec{l}\right)
$$

代码如下：

```python
def hop_x(site1, site2, phi):
    x1, y1 = site1.pos
    x2, y2 = site2.pos
    return -t * np.exp(1j * 2 * np.pi * phi * (y1 + y2) / 2)
```
