## 什么是 system，什么是 builder？

- **Builder**：`kwant.Builder()` 是一个用于构建系统的对象，它允许我们以格点和 hopping 的方式定义系统的哈密顿量。Builder 是一个未最终化的系统，可以随时添加或删除格点和 hopping。
- **System**：`syst.finalized()` 返回一个最终化的系统，这个系统是不可变的，可以用于计算。最终化的系统包含了所有的格点、hopping 和端口信息，可以用于计算能带、电导率、波函数等。

## 常见问题

### 1. 为什么我的代码报错说 `norbs` 没有指定？

新版 kwant 要求在定义晶格时指定每个格点上的轨道数，即 `norbs` 参数。例如：

```python
lat = kwant.lattice.square(a, norbs=1)  # 每个格点 1 个轨道
lat = kwant.lattice.square(a, norbs=2)  # 每个格点 2 个轨道（如自旋）
```

### 2. 如何添加磁场？

添加磁场的方法是在 hopping 项上加上一个相位因子，即 Peierls 替换：

$$
t \rightarrow t \exp\left(i \frac{e}{\hbar} \int \vec{A} \cdot d\vec{l}\right)
$$

### 3. 如何计算能带？

使用 `kwant.physics.Bands`：

```python
bands = kwant.physics.Bands(flead)
energies = [bands(k) for k in momenta]
```

### 4. 如何计算电导率？

使用 `kwant.smatrix`：

```python
smatrix = kwant.smatrix(syst, energy)
data = smatrix.transmission(1, 0)
```

### 5. 如何计算态密度？

使用 `kwant.kpm.SpectralDensity`：

```python
spectrum = kwant.kpm.SpectralDensity(fsyst, rng=0)
energies, densities = spectrum()
```
