这一节我们计算局域的量，包括磁矩、密度和流密度。

首先定义一个有磁矩分布的系统：

```python
def make_system(L=80):
    lat = kwant.lattice.square(norbs=1)
    syst = kwant.Builder()

    def square(pos):
        return all(-L/2 < p < L/2 for p in pos)

    # On-site Hamiltonian with spatially varying magnetization
    def scattering_onsite(site, r0, delta, J):
        x, y = site.pos
        m = field_direction(x, y, r0, delta)
        return J * m[2] * sigma_z  # only z component for simplicity

    syst[lat.shape(square, (0, 0))] = scattering_onsite
    syst[lat.neighbors()] = -sigma_0

    lead = kwant.Builder(kwant.TranslationalSymmetry((-1, 0)),
                         conservation_law=-sigma_z)
    lead[lat.shape(square, (0, 0))] = lead_onsite
    lead[lat.neighbors()] = -sigma_0

    syst.attach_lead(lead)
    syst.attach_lead(lead.reversed())

    return syst
```

我们可以画出 x-y 平面上 m 的投影 z 分量由颜色表示：

```python
def plot_vector_field(syst, params):
    xmin, ymin = min(s.tag for s in syst.sites)
    xmax, ymax = max(s.tag for s in syst.sites)
    x, y = np.meshgrid(np.arange(xmin, xmax+1), np.arange(ymin, ymax+1))

    m_i = [field_direction(p, **params) for p in zip(x.flat, y.flat)]
    m_i = np.reshape(m_i, x.shape + (3,))
    m_i = np.rollaxis(m_i, 2, 0)

    fig, ax = plt.subplots(1, 1)
    im = ax.quiver(x, y, *m_i, pivot='mid', scale=75)
    fig.colorbar(im)
    plt.show()

syst = make_system()
plot_vector_field(syst.finalized(), dict(r0=20, delta=10))
```

嗯这段代码是什么意思呢，首先给出 x, y 的最大和最小值，`meshgrid` 和 matlab 里面定义是一样的，就是 x 是一堆 x*y 的 x 坐标，这个二维数组我们当然要用 `flat` 变成一维数组，这样可以对每一个点计算方向向量，然后我们再画这个东西在 x, y, z 方向的分量，先把这个矩阵 reshape 为每个格点三个分量的形式：`m_i = np.reshape(m_i, x.shape + (3,))`，然后再用 `rollaxis` 对应于将第三个轴转到第一个去，本来的数组是 (x, y, i) 来标定的，也就是说原先的数组变为了第一个分量代表自旋方向，每行对应全部的 i 分量。`ax.quiver` 是 matplotlib 中向量场绘图的函数，`*mi` 是将三个分量解包，三个分量就可以正确画出了。

然后我们计算局域的数密度，实际上很简单，概率密度当然就是波函数的平方了：

```python
density = np.abs(psi)**2
```

当我们在处理有多个自由度的系统时，需要多加小心，单个格点上实际的电子数密度应当是密度矩阵的迹。

```python
# even (odd) indices correspond to spin up (down)
up, down = psi[::2], psi[1::2]
density = np.abs(up)**2 + np.abs(down)**2
```

由于我们比起局域的量，有多于一个自由度，我们可以计算磁矩在不同方向上的分量。

```python
# spin down components have a minus sign
spin_z = np.abs(up)**2 - np.abs(down)**2
```
