# 3.1 初步：构建一个简单的系统，计算电导率

### 3.1.1 离散化哈密顿量

对于偏微分方程，我们都知道怎么操作：就是化成矩阵形式，利用类似泰勒展开的公式。比如说对于哈密顿量：

$$
H = -\frac{\hbar^2}{2m}(\partial_x^2 + \partial_y^2) + V(y)
$$

我们可以将其写为：

$$
H = \sum_{i,j} \left[ (V(a_i, a_j) + 4t) \, |i,j\rangle\langle i,j| - t \left( |i+1,j\rangle\langle i,j| + |i,j\rangle\langle i+1,j| + |i,j+1\rangle\langle i,j| + |i,j\rangle\langle i,j+1| \right) \right]
$$

其中 $t = \dfrac{\hbar^2}{2ma^2}$ 对于 discretized 的系统以及 finite 的 $a$ 成立。

第一步就是定义一个有散射区域和端口的区域，对于这个我们使用 `Builder` type 来定义一个系统：

```python
syst = kwant.Builder()
```

然后定义一个晶格常数，规定一个正方晶格（一般这样好像就默认是一个 2D 的系统了）。既然是方形晶格，我们直接用 `lat(i,j)` 就可以标定特定的晶格。我们定义一个 10×30 的区域：

```python
# Define the scattering region
for i in range(L):
    for j in range(W):
        # on-site Hamiltonian
        syst[lat(i, j)] = 4 * t
        # Hopping in y direction
        if j > 0:
            syst[lat(i, j), lat(i, j - 1)] = -t

        # hopping in x-direction
        if i > 0:
            syst[lat(i, j), lat(i - 1, j)] = -t
```

上面的代码中我们实际上就是构建了一组哈密顿量，虽然我还是不太理解 `syst` 是什么意思，敢接在这里直接就是生成了一个哈密顿矩阵，在这里非对角元项由 `lat(i,j), lat(i,j-1)` 给出。即：

$$
\sum_{i,j} -t \left( |i+1,j\rangle\langle i,j| + |i,j\rangle\langle i+1,j| \right).
$$

$$
\sum_{i,j} -t \left( |i,j+1\rangle\langle i,j| + |i,j\rangle\langle i,j+1| \right).
$$

然后我们来定义端口，kwant 包中有对称性的边界直接用 `symmetry` 表示，具体来说就是这样：

```python
sym_left_lead = kwant.TranslationalSymmetry((-a, 0))
left_lead = kwant.Builder(sym_left_lead)
```

然后再去添加哈密顿量：

```python
for j in range(W):
    left_lead[lat(0, j)] = 4 * t
    if j > 0:
        left_lead[lat(0, j), lat(0, j - 1)] = -t
    left_lead[lat(1, j), lat(0, j)] = -t
```

然后利用 `Builder` 的 `attach` 指令，我们就把端口接上去了：

```python
syst.attach_lead(left_lead)
```

接下来我们再定义右端口：

```python
sym_right_lead = kwant.TranslationalSymmetry((a, 0))
right_lead = kwant.Builder(sym_right_lead)
for j in range(W):
    right_lead[lat(0, j)] = 4 * t
    if j > 0:
        right_lead[lat(0, j), lat(0, j - 1)] = -t
    right_lead[lat(1, j), lat(0, j)] = -t
syst.attach_lead(right_lead)
```

#### 本节用到的代码总结

- `kwant.Builder()`：构建系统的调用名称，`syst = kwant.Builder()` 括号里面什么都不加我也不知道是什么意思，反正说就是创建了一个体系。
- `kwant.lattice.square`：构建正方形晶格。
- `kwant.TranslationalSymmetry((-a, 0))`：构造具有平移对称性的系统，向 `-a` 方向平移。
- `kwant.Builder(sym_left_lead)`：构造一个左边的端口，具有对称性。
- `syst[lat(i,j), lat(k,l)]`：第 `(i,j)` 位置的原子和第 `(k,l)` 的原子相互作用的哈密顿量。
- `syst.attach_lead`：添加一个端口，在前面 builder 里面声明是哪边的就加在哪边。
- `syst.finalized()`：最终化我们的模型，使得能够进行后续的计算。
- `smatrix(syst, energy)`：注意这里面的 `syst` 要求是已经最终化的系统，然后这里的 `energy` 就是我们的入射能量。

### 3.1.3 尝试用更少的代码

现在我们重新构造同样的系统，但是我们希望用更少的代码（注意新版 kwant 要求指定轨道数才能运行，这是不同于说明书上的一点，如果 `lat` 里面不打 `norb` 数会报错）：

```python
import kwant

# For plotting
from matplotlib import pyplot as plt

def make_system(a=1, t=1.0, W=10, L=30):
    lat = kwant.lattice.square(a, norbs=1)

    syst = kwant.Builder()

    syst[(lat(x, y) for x in range(L) for y in range(W))] = 4 * t

    syst[lat.neighbors()] = -t
```

这里代码的意思一一对应前面的内容已经很清楚了，就是说 `neighbors` 意思就是邻近原子之间的相互作用，然后这里直接可以把循环语句写在里面就挺神奇的。接下来是对端口的定义：

```python
    lead = kwant.Builder(kwant.TranslationalSymmetry((-a, 0)))
    lead[(lat(0, j) for j in range(W))] = 4 * t
    lead[lat.neighbors()] = -t
```

然后我们使用 `syst.attach_lead(lead.reversed())` 直接把左边的端口对称地接到了右边，总的定义语段如下：

```python
def make_system(a=1, t=1.0, W=10, L=30):
    lat = kwant.lattice.square(a, norbs=1)

    syst = kwant.Builder()

    syst[(lat(x, y) for x in range(L) for y in range(W))] = 4 * t

    syst[lat.neighbors()] = -t

    lead = kwant.Builder(kwant.TranslationalSymmetry((-a, 0)))
    lead[(lat(0, j) for j in range(W))] = 4 * t
    lead[lat.neighbors()] = -t
    syst.attach_lead(lead)
    syst.attach_lead(lead.reversed())
    return syst
```

接下来的内容被分为两部分，一部分是处理电导率的部分（里面 `pyplot` 被我换成 `plt` 了）：

```python
def plot_conductance(syst, energies):
    # Compute conductance
    data = []
    for energy in energies:
        smatrix = kwant.smatrix(syst, energy)
        data.append(smatrix.transmission(1, 0))
    plt.figure()
    plt.plot(energies, data)
    plt.xlabel("energy [t]")
    plt.ylabel("conductance [e^2/h]")
    plt.show()
```

另一部分是主程序：

```python
def main():
    syst = make_system()
    # Check that the system looks as intended.
    kwant.plot(syst)
    # Finalize the system.
    syst = syst.finalized()
    # We should see conductance steps.
    plot_conductance(syst, energies=[0.01 * i for i in range(100)])

if __name__ == '__main__':
    main()
```
