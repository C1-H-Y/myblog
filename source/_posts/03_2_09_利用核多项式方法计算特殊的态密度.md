这一节我们介绍如何利用核多项式方法（KPM, Kernel Polynomial Method）计算特殊的态密度。KPM 是一种用于计算大系统态密度的方法，它通过将态密度展开为 Chebyshev 多项式的级数来近似计算。

首先定义一个 honeycomb 系统：

```python
def make_system(r=10, t=-1, a=1):
    syst = kwant.Builder()
    lat = kwant.lattice.honeycomb(a, norbs=1)

    def circle(pos):
        x, y = pos
        return x**2 + y**2 < r**2

    syst[lat.shape(circle, (0, 0))] = 0.
    syst[lat.neighbors()] = t
    syst.eradicate_dangling()

    return syst
```

定义完了之后我们就可以用 KPM 计算态密度了：

```python
fsyst = make_system().finalized()

spectrum = kwant.kpm.SpectralDensity(fsyst, rng=0)

energies, densities = spectrum()
```

而且通过对整个区域内的态密度积分我们还可以得到区域内总的粒子数有多少：

```python
print('identity resolution:', spectrum.integrate())
```

输出：

```
identity resolution: (6492.999999999999-3.855043762418534e-31j)
```

当然我们应该用费米分布积分，假定化学势大小为 0.1，温度 0.2：

```python
# Fermi energy 0.1 and temperature 0.2
fermi = lambda E: 1 / (np.exp((E - 0.1) / 0.2) + 1)
print('number of filled states:', spectrum.integrate(fermi))
```

输出结果为：

```
number of filled states: (3306.7989795427643-6.896600008816472e-15j)
```

## 局部的谱密度

当然我们也可以不用 KPM 直接算局部的态密度，这里我们将单位元胞拆开来，分别计算 A, B 的态密度：

```python
fsyst = make_system().finalized()
center_tag = np.array([0, 0])
where = lambda s: s.tag == center_tag
# make local vectors
vector_factory = kwant.kpm.LocalVectors(fsyst, where)

# 'num_vectors' can be unspecified when using 'LocalVectors'
local_dos = kwant.kpm.SpectralDensity(fsyst, num_vectors=None,
                                     vector_factory=vector_factory,
                                     mean=False,
                                     rng=0)
energies, densities = local_dos()

def plot_dos(labels_to_data):
    plt.figure()
    for label, (x, y) in labels_to_data:
        plt.plot(x, y.real, label=label, linewidth=2)
    plt.legend(loc=2, framealpha=0.5)
    plt.xlabel("energy [t]")
    plt.ylabel("DoS [a.u.]")
    plt.show()
```

我们得到两条曲线，分别代表 A, B 格点各自的态密度：

## 增加近似的精确度

`SpectralDensity` 有两个参数来控制近似的精确度：`num_moments` 和 `num_rand_vecs`。增加这两个参数可以提高近似的精确度，但也会增加计算时间。

```python
spectrum = kwant.kpm.SpectralDensity(fsyst, num_moments=200, num_rand_vecs=10, rng=0)
```
