这一节我们介绍如何用不同的风格绘制 kwant 系统及数据。kwant 提供了多种绘图风格，可以让我们更好地可视化系统。

首先定义一个 honeycomb 晶格：

```python
import numpy as np
import kwant

graphene = kwant.lattice.honeycomb(a=1, norbs=1)
a, b = graphene.sublattices
```
