02 Kwant 简介
发表于2026-07-21|kwant
2.1 关于 kwantkwant 是一个用于数据计算紧束缚近似下量子输运相关模型的 python 包，通常来说比其他可用的组件速度要更快一点，甚至快于那些完全用 FORTRAN 或者 C++ 写的（但其实除了关心极大量的模型的组通常快不快无所谓）。 紧束缚模型可以解释一系列量子现象，比如说金属、石墨烯、拓扑绝缘体、量子霍尔效应、超导、自旋极化器件。 Kwant 可以计算：量子输运、扩散关系、波函数、各种各样的格林函数、非平衡态系统。 顺便，他在这里也提到了 Datta 的书，确实不错，建议先看完用 matlab 跟着做一下课后作业。其实是有两本，一本 From Atom to Transistor，一本 Nanostructure。 2.2 What’s New in kwant好吧这个其实我还用不太到。
