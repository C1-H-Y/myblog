这一节我们考虑超导系统。超导系统需要引入电子和空穴两个自由度，即 Nambu 表示。同时，超导系统具有粒子-空穴对称性，这是一个守恒律。

首先定义泡利矩阵和超导配对项：

```python
import numpy as np
import tinyarray

sigma_0 = tinyarray.array([[1, 0], [0, 1]])
sigma_x = tinyarray.array([[0, 1], [1, 0]])
sigma_y = tinyarray.array([[0, -1j], [1j, 0]])
sigma_z = tinyarray.array([[1, 0], [0, -1]])

# Pauli matrices for electron-hole (tau) and spin (sigma) spaces
tau_x = tinyarray.array(np.kron(sigma_x, sigma_0))
tau_y = tinyarray.array(np.kron(sigma_y, sigma_0))
tau_z = tinyarray.array(np.kron(sigma_z, sigma_0))
```

然后定义散射区域的哈密顿量：

```python
def make_system(a=1, t=1.0, W=10, L=30, Delta=0.1):
    lat = kwant.lattice.square(a, norbs=4)

    syst = kwant.Builder()

    # On-site Hamiltonian: BdG Hamiltonian
    def onsite(site, mu):
        return (4 * t - mu) * tau_z + Delta * tau_x

    syst[(lat(x, y) for x in range(L) for y in range(W))] = onsite

    # Hopping
    def hop(site1, site2):
        return -t * tau_z

    syst[lat.neighbors()] = hop

    # Lead with conservation law
    lead = kwant.Builder(kwant.TranslationalSymmetry((-a, 0)),
                         conservation_law=-tau_z)
    lead[(lat(0, j) for j in range(W))] = onsite
    lead[lat.neighbors()] = hop

    syst.attach_lead(lead)
    syst.attach_lead(lead.reversed())

    return syst
```

注意这里我们使用了 `conservation_law=-tau_z`，这告诉 kwant 端口具有粒子-空穴守恒律，kwant 会自动把端口分成电子和空穴两个子空间。
